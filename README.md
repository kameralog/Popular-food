# О каком блюде читают чаще? — сборка со звуком

Распакуйте архив. Загрузите index.html, папку assets и .nojekyll в корень репозитория игры. Не загружайте ZIP как файл сайта и не заменяйте главную страницу другого проекта.

Структура:
index.html
assets/fork_on_plate.wav
assets/burp.wav
.nojekyll

Для нового сайта: публичный репозиторий → Settings → Pages → Deploy from a branch → main → / (root) → Save.
Для обновления существующего сайта замените index.html и добавьте assets.

Правильный ответ: синтетическая вилка по тарелке. Неправильный: синтетическая отрыжка. Ничья: без звука. Переключатель звука сохраняется в браузере. Звуки не воспроизводятся при загрузке.

Фото и описания видны до ответа; числа после. Статистика, картинки и описания загружаются через Wikimedia API. Нужен интернет. Первое получение данных может занять время. Прототип не проверен в живом браузере в этой среде.

Метрика не равна мировой популярности: это сумма просмотров связанных статей в восьми языковых разделах. Фото и статьи имеют собственные лицензии: перед широким релизом подготовьте авторство и атрибуцию. Звуки созданы процедурным синтезом.
