# О каком блюде читают чаще? — раунды по 10 страниц

Распакуйте архив. Загрузите index.html, assets/ и .nojekyll в корень репозитория игры с заменой старых файлов. ZIP загружать не нужно. Для нового сайта: публичный репозиторий → Settings → Pages → Deploy from a branch → main → / (root).

Каждый раунд состоит из 10 успешных сравнений. Недоступные пары можно пропускать, они не расходуют страницы. После десятого ответа нажмите «Обзор раунда»: десять карточек, каждая с двумя блюдами, выбором игрока, результатом и числом просмотров. Кнопка «О блюде» открывает внутреннюю страницу с фото, расширенным введением из Википедии, статистикой и ссылками на источники. Возврат сохраняет обзор в памяти вкладки. Кнопка следующего раунда очищает текущий обзор; архив прошлых раундов не реализован.

100 блюд идут из очереди без повторов внутри цикла. Звуки сохранены: вилка — верно, отрыжка — ошибка. Ничья без звука. Фото и названия видны до выбора. Описания: русская Википедия с резервом на другие языки, без автоматического перевода.

Внутренние страницы используют hash-маршрутизацию (#dish/...), не требуют настройки сервера и подходят для GitHub Pages. Прогресс не переживает перезагрузку страницы; кеш статистики и настройка звука сохраняются локально.

Статистика не измеряет мировую популярность: это просмотры восьми языковых версий статей. Требуется интернет. Перед широким релизом проверьте лицензии и атрибуцию снимков. Ручная проверка всех карточек и тестирование в браузере здесь не выполнены.
